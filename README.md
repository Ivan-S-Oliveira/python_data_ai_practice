# 🐍 Python AI Practice

Repositório criado para estudar e praticar **Python aplicado a Dados, Automação, Machine Learning e Inteligência Artificial**.

Este repositório complementa o [programming-practice](../programming-practice), que é focado em exercícios gerais de programação e fundamentos das diferentes linguagens.

Aqui o foco é utilizar Python para trabalhar com **dados, APIs, automação e conceitos de IA**.

---

## Objetivos

* Aprimorar conhecimentos em Python
* Praticar manipulação e análise de dados
* Aprender bibliotecas utilizadas em Data Science
* Trabalhar com APIs e dados em formato JSON
* Automatizar tarefas utilizando Python
* Compreender conceitos fundamentais de Machine Learning
* Desenvolver pequenos experimentos de Inteligência Artificial
* Utilizar JupyterLab para exploração e análise de dados
